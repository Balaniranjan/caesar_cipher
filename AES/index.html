What is AES?

AES stands for Advanced Encryption Standard. It is a symmetric-key encryption algorithm used to protect digital information.

In symmetric encryption, the same secret key is used for encryption and decryption.

AES Operations

SubBytes

Each byte in the state is replaced with another byte using the AES S-Box.

ShiftRows

The bytes in each row of the state are shifted by different positions.

MixColumns

The bytes in each column are mathematically mixed to provide diffusion.

AddRoundKey

The current state is combined with a round key using XOR.
