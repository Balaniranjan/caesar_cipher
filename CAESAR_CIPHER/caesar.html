Experiment 1: Caesar Cipher

Aim

To implement the Caesar Cipher technique for encryption and decryption of a given plaintext using a specified shift value.

Algorithm

  1. Read the plaintext.
  2. Read the shift value.
  3. For each alphabetic character, shift it by the specified number of positions.
  4. If the shift goes beyond Z, wrap around to the beginning of the alphabet.
  5. Preserve spaces, numbers and special characters.
  6. Generate the ciphertext.
  7. For decryption, shift the characters in the opposite direction.
Encryption: C = (P + K) mod 26
Decryption: P = (C - K) mod 26
P = Plaintext, C = Ciphertext, K = Shift value

Working Principle

Caesar Cipher is a substitution cipher in which each alphabetic character is replaced by another character obtained by shifting it by a fixed number of positions in the alphabet.

Example:

Plaintext : HELLO
Shift : 3
Ciphertext : KHOOR

Character transformation breakdown for shift of 3:

H → K
E → H
L → O
L → O
O → R

Each character moves three positions forward.

Wrap-around rule (Shift = 3):

X → A
Y → B
Z → C

Original Shift Result
A+3D
B+3E
C+3F
H+3K
X+3A
Y+3B
Z+3C

Python Implementation
def caesar_encrypt(text, shift):
    result = ""

    for char in text:
        if char.isalpha():
            base = ord('A') if char.isupper() else ord('a')
            result += chr((ord(char) - base + shift) % 26 + base)
        else:
            result += char

    return result


def caesar_decrypt(text, shift):
    return caesar_encrypt(text, -shift)


text = input("Enter plaintext: ")
shift = int(input("Enter shift value: "))

ciphertext = caesar_encrypt(text, shift)

print("Ciphertext:", ciphertext)

decrypted = caesar_decrypt(ciphertext, shift)

print("Decrypted text:", decrypted)
Java Implementation
import java.util.Scanner;

public class CaesarCipher {
    public static String encrypt(String text, int shift) {
        StringBuilder result = new StringBuilder();
        int shiftMod = shift % 26;
        if (shiftMod < 0) shiftMod += 26;

        for (char character : text.toCharArray()) {
            if (Character.isLetter(character)) {
                char base = Character.isUpperCase(character) ? 'A' : 'a';
                result.append((char) (((character - base + shiftMod) % 26) + base));
            } else {
                result.append(character);
            }
        }
        return result.toString();
    }

    public static String decrypt(String text, int shift) {
        return encrypt(text, -shift);
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Enter plaintext: ");
        String text = scanner.nextLine();
        
        System.out.print("Enter shift value: ");
        int shift = scanner.nextInt();
        
        String ciphertext = encrypt(text, shift);
        System.out.println("Ciphertext: " + ciphertext);
        
        String decrypted = decrypt(ciphertext, shift);
        System.out.println("Decrypted text: " + decrypted);
        
        scanner.close();
    }
}
C++ Implementation
#include <iostream>
#include <string>
#include <cctype>

using namespace std;

string encrypt(string text, int shift) {
    string result = "";
    int shiftMod = shift % 26;
    if (shiftMod < 0) shiftMod += 26;
    
    for (char character : text) {
        if (isalpha(character)) {
            char base = isupper(character) ? 'A' : 'a';
            result += char((character - base + shiftMod) % 26 + base);
        } else {
            result += character;
        }
    }
    return result;
}

string decrypt(string text, int shift) {
    return encrypt(text, -shift);
}

int main() {
    string text;
    int shift;

    cout << "Enter plaintext: ";
    getline(cin, text);

    cout << "Enter shift value: ";
    cin >> shift;

    string ciphertext = encrypt(text, shift);
    cout << "Ciphertext: " << ciphertext << endl;

    string decrypted = decrypt(ciphertext, shift);
    cout << "Decrypted text: " << decrypted << endl;

    return 0;
}
